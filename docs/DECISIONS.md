# Decisions

จุดที่แผนไม่ได้ระบุ และทางที่เลือกไว้

## D001 — ต้นแบบเป็นแหล่งของสีและตัวเลขตัวอย่าง

ต้นแบบอยู่ที่ `docs/prototype/App.js` และห้ามแก้ไฟล์นั้น `server/src/db/prototype.ts` อ่านวัตถุ `C`, พืช 5 ชนิด, ผู้ซื้อ 3 ราย และล็อต 3 ล็อตจากไฟล์นี้ตอน `npm run seed` แล้วคัดลอกค่าใน `C` ไป `mobile/src/theme.ts`

ใน workspace ของรอบนี้ยังเปิดไฟล์นั้นไม่พบ จึงยังไม่ใส่สี และยังรัน seed เพื่อยืนยันจำนวนแถวไม่ได้

## D002 — migrate และ seed เชื่อม MySQL ผ่าน TCP

`migrate` สร้างฐานข้อมูลตาม `DB_NAME` ถ้ายังไม่มี แล้วรัน SQL ใน `server/src/db/migrations/` `seed` แทรกเฉพาะแถวที่ยังไม่มี จึงรันซ้ำได้โดยจำนวนแถวไม่เพิ่ม ทั้งคู่ใช้โฮสต์ `127.0.0.1` ไม่ใช้ unix socket

## D006 — ตาราง schema_migrations

แผนไม่ได้กำหนดตารางนี้ ใช้เก็บชื่อไฟล์ migration ที่รันแล้ว เพื่อไม่ให้ `npm run migrate` รัน SQL เดิมซ้ำ ไม่มี FOREIGN KEY และไม่มี VIEW

## D007 — บัญชีที่ต้นแบบไม่มีเบอร์หรือชื่อ

รหัสผ่านทุกบัญชีตัวอย่างคือ `demo1234` ถ้าต้นแบบไม่มีเบอร์หรือไม่มีผู้ใช้ role นั้น ใช้ค่านี้

| role | name | phone |
|---|---|---|
| farmer | เกษตรกรตัวอย่าง | 0800000001 |
| driver | คนขับตัวอย่าง | 0800000002 |
| coordinator | ผู้ประสานตัวอย่าง | 0800000003 |
| buyer ลำดับที่ 1–3 | ชื่อจากต้นแบบ | 0800000011, 0800000012, 0800000013 |

เบอร์สำรองใช้เฉพาะเมื่อต้นแบบไม่มีเบอร์ ผู้ซื้อยังใช้ชื่อ `buyer_type` และพิกัดจากต้นแบบ

## D008 — เวลาของล็อตและแถว quality assessment

ถ้าต้นแบบไม่ระบุเวลาสร้างล็อต ใช้ `2026-09-22T02:00:00Z` (09:00 เวลาไทย) แล้วตั้ง `expires_at` จากอายุการขายเป็นชั่วโมง ถ้าต้นแบบมีค่าอายุการขายอยู่แล้ว ใช้ค่านั้นตรง ๆ ถ้าไม่มีอุณหภูมิหรือความชื้น ใช้ 32°C และ 75% ตามแผน ใส่ `quality_assessments` หนึ่งแถวต่อล็อตด้วย `method = 'rule'`

ถ้าต้นแบบไม่มี `area_rai` ของแปลง seed จะหยุด เพื่อไม่ใส่พื้นที่ที่ต้นแบบไม่ได้ให้มา

## D009 — บัญชี MySQL บนเครื่องนี้

workspace ไม่มี `server/.env` จึงสร้างไฟล์นี้ในเครื่องให้เชื่อม TCP `127.0.0.1:3306` ด้วยผู้ใช้ `agri` รหัส `agri-rescue` ฐาน `agri_rescue` บัญชี root ของ MySQL บนเครื่องนี้เข้าได้ทาง socket จึงไม่ใช้กับแอป ไฟล์ `.env` ไม่ถูก commit

## D003 — เทมเพลตมือถือเป็น `tabs`

ใช้ `npx create-expo-app mobile --template tabs` ซึ่งเป็น TypeScript และ Expo Router โฟลเดอร์ `(auth)`, `(farmer)`, `(buyer)`, `(driver)`, `(coordinator)` มีแค่ `.gitkeep` เพราะ Expo Router โหลดไฟล์ `.ts` / `.tsx` ใน `app/` เป็นหน้าจอ หน้าแท็บของเทมเพลตจึงยังเปิดได้ก่อน Phase 5 โฟลเดอร์ `components/` กับ `constants/` ที่เทมเพลตสร้างไว้คงเดิม โค้ดของโปรเจกต์อยู่ใต้ `mobile/src/`

## D004 — พิกัดคลังตัวอย่างใน `.env.example`

แผนกำหนดชื่อ `DEPOT_LAT` และ `DEPOT_LNG` แต่ไม่ได้กำหนดค่า ค่าตัวอย่างใช้ใจกลางกรุงเทพฯ `13.7563, 100.5018`

## D005 — เซิร์ฟเวอร์ใช้ CommonJS

`tsconfig` ตั้ง `module` เป็น `commonjs` เพื่อให้ Express, Jest และ ts-jest ทำงานร่วมกันโดยไม่ตั้งค่า ESM เพิ่ม
