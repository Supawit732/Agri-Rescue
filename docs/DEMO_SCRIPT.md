# สคริปต์เดโม 5 นาที (Internet Programming)

เป้าหมาย: โชว์ flow จริงบนมือถือ — login หลายบทบาท, ทุกแท็บหลัก, ลงล็อต+AI, จอง, ยืนยันรับด้วย OTP, แดชบอร์ดอัปเดต, admin อนุมัติองค์กร

เตรียมเครื่องตาม [DEVICE_DEMO.md](./DEVICE_DEMO.md) และรัน `npm run seed:demo` แล้ว

รหัสผ่านทุกบัญชี: `demo1234`

| นาที | ใคร | ทำอะไร |
|---|---|---|
| 0:00–0:40 | ผู้ซื้อ `0800000011` | Login → แท็บตลาด / คำสั่งซื้อ / แจ้งเตือน / บัญชี |
| 0:40–1:40 | เกษตรกร `0800000001` | Login → ลงล็อต + AI → ประกาศ |
| 1:40–2:40 | ผู้ซื้อ | จองล็อตที่เพิ่งลง → ดู OTP |
| 2:40–3:30 | เกษตรกร | ยืนยันรับของด้วย OTP + น้ำหนัก → แดชบอร์ด |
| 3:30–4:20 | admin `0800000005` | Admin อนุมัติองค์กร + แดชบอร์ดทั้งระบบ |
| 4:20–5:00 | (สำรอง) | ลบ/ปิดล็อตที่ยังไม่มีออเดอร์ หรือสลับแท็บขาย/บริจาค |

---

## 0:00 — เปิดฉาก + ผู้ซื้อ (≈40 วินาที)

1. เปิด Expo Go บนมือถือ → เข้าแอป  
2. Login: **รถพุ่มพวงป้าแดง** `0800000011` / `demo1234`  
3. กวาดแท็บเร็ว ๆ (พูดสั้น ๆ):
   - **ตลาด** — ล็อตใกล้หมดอายุ / กดเข้าดูรายละเอียดได้  
   - **คำสั่งซื้อ** — ประวัติจอง  
   - **แจ้งเตือน** — รายการในแอป  
   - **บัญชี** — โปรไฟล์ / สมัครรับบริจาค (อย่าเข้าแดชบอร์ดตอนนี้ — ผู้ซื้ออย่างเดียวจะถูกปฏิเสธ)

ประโยคแนะนำ: “ผู้ซื้อเห็นตลาดและจองได้ แต่แดชบอร์ดผลลัพธ์เป็นของเกษตรกรกับแอดมิน”

---

## 0:40 — เกษตรกรลงล็อต + AI (≈60 วินาที)

1. ออกจากระบบ → Login **ลุงสมชาย** `0800000001`  
2. แท็บ **ขาย** → ลงล็อตใหม่  
3. เลือกพืช / เกรด / ถ่ายหรือเลือกภาพผลผลิต  
4. กดประเมินด้วย AI (ถ้ามี API key) — โชว์ความสุกที่โมเดลเสนอ แล้วเกษตรกรยืนยันหรือแก้เอง  
5. กรอกน้ำหนัก > 0 → ดู preview ราคา/อายุการขาย → **ลงประกาศ**  
6. (ทางเลือก 10 วิ) แท็บขาย → ล็อตของฉัน — ชี้ปุ่ม **ลบ/ปิดล็อต** ว่าใช้ได้เมื่อยังไม่มีออเดอร์ และมี dialog ยืนยัน

ประโยคแนะนำ: “ราคาและอายุคำนวณจากความสุกกับอากาศที่แปลง ไม่ใช่ราคาตลาดคงที่”

---

## 1:40 — ผู้ซื้อจอง (≈60 วินาที)

1. Logout → Login `0800000011` อีกครั้ง  
2. แท็บตลาด → หารายการที่เพิ่งลง (หรือล็อตเปิดจาก seed)  
3. จองจำนวนกก. → ยืนยัน  
4. เปิด **คำสั่งซื้อ** → รายละเอียด → ชี้ **รหัส OTP 4 หลัก** (เก็บไว้พูดตอนส่งมอบ)

ประโยคแนะนำ: “ผู้ซื้อไม่โอนเงินในแอปตอนนี้ — จ่ายที่จุดรับ; OTP คือหลักฐานรับของ”

---

## 2:40 — เกษตรกรยืนยันรับ + แดชบอร์ด (≈50 วินาที)

1. Logout → Login `0800000001`  
2. แท็บ **ขาย** → ล็อตของฉัน → กดรายการ **ผู้จอง** เพื่อเปิดออเดอร์  
3. ฝั่งผู้ขาย: กรอก **OTP ที่ผู้ซื้อให้** + **น้ำหนักที่ชั่งได้** → ยืนยันส่งมอบ  
4. แท็บบัญชี → **แดชบอร์ด**  
   - การ์ด: กก. ที่ช่วยได้, CO₂e, รายได้, กก. บริจาค, จำนวนออเดอร์  
   - กราฟ 14 วัน / แยกพืช / สถานะออเดอร์ / ความแม่นยำ AI  

ประโยคแนะนำ: “หลังส่งมอบ ตัวเลข impact และกราฟอัปเดตทันที — ข้อมูลย้อนหลัง 14 วันมาจาก `seed:demo`”

---

## 3:30 — Admin อนุมัติองค์กร (≈50 วินาที)

1. Logout → Login **admin** `0800000005` (มี `is_admin`)  
2. เปิดหน้า **แอดมิน** (`/admin`) — คิวใบสมัครองค์กรที่รออนุมัติ  
3. อนุมัติหรือดูรายละเอียดเอกสาร (ถ้ามี pending จากเดโมก่อนหน้า; ถ้าคิวว่าง ให้พูดว่าสมัครได้จากบัญชีผู้ซื้อ → สมัครรับบริจาค แล้วกลับมาอนุมัติ)  
4. บัญชี → **แดชบอร์ด** — ขอบเขต “ภาพรวมทั้งระบบ” (ต่างจากแดชบอร์ดเกษตรกรที่เห็นเฉพาะของตน)

---

## 4:20 — สำรองถ้าเหลือเวลา

- แสดงล็อต `sell_then_donate` / ป้ายรับบริจาคหลังเปิดหน้าต่างบริจาค  
- คนขับ `0800000004` หรือผู้ประสานสร้างรอบวิ่ง (flow เต็ม — ใช้เมื่อมีเวลา > 5 นาที)  
- ลบล็อตเปิดที่ยังไม่มีออเดอร์ แล้วรีเฟรชตลาดว่าหายไป
