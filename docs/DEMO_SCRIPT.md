# สคริปต์เดโม 5 นาที (Internet Programming)

เป้าหมาย: โชว์ flow จริงบนมือถือ — login หลายบทบาท, แท็บหลัก, ลงล็อต+AI, จอง, ยืนยันรับด้วย OTP, แดชบอร์ดอัปเดต, admin อนุมัติองค์กร

เตรียมเครื่องตาม [DEVICE_DEMO.md](./DEVICE_DEMO.md) และรัน `npm run seed:demo` แล้ว

รหัสผ่านทุกบัญชี: `demo1234`

> **โครงแอปปัจจุบัน:** 4 แท็บ — **ตลาด / ขาย / คำสั่งซื้อ / แจ้งเตือน**  
> บัญชี/เมนูอยู่ที่ **รูปโปรไฟล์มุมขวาบน** (ไม่มีแท็บ “บัญชี” แล้ว)

| นาที | ใคร | ทำอะไร |
|---|---|---|
| 0:00–0:40 | ผู้ซื้อ `0800000011` | Login → แท็บตลาด / คำสั่งซื้อ / แจ้งเตือน + เมนูโปรไฟล์ |
| 0:40–1:40 | เกษตรกร `0800000001` | Login → แท็บขาย ลงล็อต + AI → ประกาศ |
| 1:40–2:40 | ผู้ซื้อ | จองล็อตที่เพิ่งลง → ดู OTP |
| 2:40–3:30 | เกษตรกร | ยืนยันรับของด้วย OTP + น้ำหนัก → แดชบอร์ดจากเมนู |
| 3:30–4:20 | admin `0800000005` | ผู้ดูแล → อนุมัติองค์กร + แดชบอร์ดระบบ |
| 4:20–5:00 | (สำรอง) | ตลาด/ตัวกรอง, ร้านที่ติดตาม, ติดต่อเรา |

---

## 0:00 — เปิดฉาก + ผู้ซื้อ (≈40 วินาที)

1. เปิด Expo Go บนมือถือ → เข้าแอป  
2. Login: **รถพุ่มพวงป้าแดง** `0800000011` / `demo1234`  
3. กวาดแท็บเร็ว ๆ (พูดสั้น ๆ):
   - **ตลาด** — ล็อตใกล้หมดอายุ / กดเข้าดูรายละเอียด / ปุ่มตัวกรอง  
   - **ขาย** — (ผู้ซื้ออย่างเดียวเห็นคำอธิบายเปิดการขาย)  
   - **คำสั่งซื้อ** — ประวัติจอง  
   - **แจ้งเตือน** — รายการในแอป (ถ้ามี unread ขึ้น badge)  
4. แตะ **รูปโปรไฟล์มุมขวาบน** → เมนู: ร้านของฉัน / ร้านที่ติดตาม / ติดต่อเรา / รับบริจาค / ภาษา / ออกจากระบบ  
   - **อย่ากดแดชบอร์ด** ถ้าบัญชีนี้ไม่ได้เปิดการขาย (ปุ่มจะไม่ขึ้นเมื่อไม่ใช่ผู้ขาย/admin)

ประโยคแนะนำ: “ผู้ซื้อเห็นตลาดและจองได้ แต่แดชบอร์ดผลลัพธ์เป็นของเกษตรกรกับแอดมิน”

---

## 0:40 — เกษตรกรลงล็อต + AI + ราคาตามฤดูกาล (≈60 วินาที)

1. เมนูโปรไฟล์ → **ออกจากระบบ** → Login **ลุงสมชาย** `0800000001`  
2. แท็บ **ขาย** → ลงล็อตใหม่  
3. เลือกพืช (เช่น **ส้มโอ** หรือ **มังคุด**) — คลังพืชมี 30+ รายการ ถ้าหาไม่เจอกด “เพิ่มพืชใหม่” → พิมพ์ชื่อ → ระบบอนุมัติทันที  
4. เลือกเกรด / ถ่ายหรือเลือกภาพผลผลิต  
5. กดประเมินด้วย AI (ถ้ามี API key) — โชว์ความสุกที่โมเดลเสนอ แล้วเกษตรกรยืนยันหรือแก้เอง  
6. กรอกน้ำหนัก > 0 → ดู **preview ราคา** — ถ้าพืชมีปัจจัยฤดูกาล (เช่น ส้มโอในเดือนตุลาคม) จะเห็นป้าย “ราคาฤดูกาล” และราคาที่ถูกลงตามอุปทาน → **ลงประกาศ**  
7. เมนูโปรไฟล์ → **ร้านของฉัน** โชว์หน้าร้าน + สถิติ

ประโยคแนะนำ: “ราคา fallback คำนวณจากฐาน × ปัจจัยฤดูกาล ช่วงเก็บเกี่ยวพีคอุปทานสูงราคาจึงลด ส้มโอตุลาคมแสดงผลต่างชัดเจน”

---

## 1:40 — ผู้ซื้อจอง (≈60 วินาที)

1. เมนู → Logout → Login `0800000011` อีกครั้ง  
2. แท็บตลาด → หารายการที่เพิ่งลง (หรือล็อตเปิดจาก seed)  
3. จองจำนวนกก. → ยืนยัน  
4. เปิด **คำสั่งซื้อ** → รายละเอียด → ชี้ **รหัส OTP 4 หลัก** (เก็บไว้พูดตอนส่งมอบ)

ประโยคแนะนำ: “ผู้ซื้อไม่โอนเงินในแอปตอนนี้ — จ่ายที่จุดรับ; OTP คือหลักฐานรับของ”

---

## 2:40 — เกษตรกรยืนยันรับ + แดชบอร์ด (≈50 วินาที)

1. เมนู → Logout → Login `0800000001`  
2. แท็บ **ขาย** → ล็อตของฉัน → กดรายการ **ผู้จอง** เพื่อเปิดออเดอร์  
3. ฝั่งผู้ขาย: กรอก **OTP ที่ผู้ซื้อให้** + **น้ำหนักที่ชั่งได้** → ยืนยันส่งมอบ  
4. เมนูโปรไฟล์ → **แดชบอร์ด**  
   - การ์ด: กก. ที่ช่วยได้, CO₂e, รายได้, กก. บริจาค, จำนวนออเดอร์  
   - กราฟ 14 วัน / แยกพืช / สถานะออเดอร์ / ความแม่นยำ AI  

ประโยคแนะนำ: “หลังส่งมอบ ตัวเลข impact และกราฟอัปเดตทันที — ข้อมูลย้อนหลัง 14 วันมาจาก `seed:demo`”

---

## 3:30 — Admin อนุมัติองค์กร (≈50 วินาที)

1. เมนู → Logout → Login **admin** `0800000005` (มี `is_admin`)  
2. เมนูโปรไฟล์ → **ผู้ดูแลระบบ** (`/admin`)  
3. แท็บ **คำขอองค์กร** — คิวใบสมัครที่รออนุมัติ  
4. อนุมัติหรือดูรายละเอียดเอกสาร (ถ้ามี pending จากเดโมก่อนหน้า; ถ้าคิวว่าง ให้พูดว่าสมัครได้จากบัญชีผู้ซื้อ → สมัครรับบริจาค แล้วกลับมาอนุมัติ)  
5. แท็บ **ติดต่อเรา** — ถ้ามีเรื่องค้าง (ตัวเลือก)  
6. เมนู → **แดชบอร์ด** — ขอบเขต “ภาพรวมทั้งระบบ” (ต่างจากแดชบอร์ดเกษตรกรที่เห็นเฉพาะของตน)

---

## 4:20 — สำรองถ้าเหลือเวลา

- **ตลาด**: ค้นหาพืช/ชื่อร้าน, ตัวกรองระยะ/ราคา/เวลา  
- หน้าร้าน → ปุ่ม **ติดตามร้าน** → เมนู **ร้านที่ติดตาม**  
- เมนู **ติดต่อเรา** → แจ้งเรื่องสั้น ๆ  
- แสดงล็อต `sell_then_donate` / ป้ายรับบริจาคหลังเปิดหน้าต่างบริจาค  
- ลบล็อตเปิดที่ยังไม่มีออเดอร์ แล้วรีเฟรชตลาดว่าหายไป  

> **ไม่ใช้ในเดโมสั้น:** LINE Login, ปุ่มยกเลิกออเดอร์จากหน้า support, escrow (planned: future release)
