# เดโม Agri-Rescue — flow เต็ม 4 role

คู่มือนี้เดินระบบตั้งแต่เกษตรกรลงล็อต จนถึงหน้าผลลัพธ์ (impact) ผ่านแอป Expo โดยใช้บัญชีจาก seed

## เตรียมระบบ

เซิร์ฟเวอร์ (โฟลเดอร์ `server/`) ต้องมี MySQL 8 ที่ `127.0.0.1:3306` และไฟล์ `.env` (ดู `README.md`)

```bash
cd server
npm install
npm run migrate
npm run seed:reset   # ล้างออเดอร์/รอบ/ผลลัพธ์เก่า และตั้ง expires_at ใหม่ให้ล็อตตัวอย่าง
npm run seed         # ใส่ผู้ใช้ พืช แปลง และล็อตตัวอย่าง (ข้ามแถวที่มีอยู่แล้ว)
npm run dev          # API ที่ http://localhost:3000
```

แอปมือถือ (โฟลเดอร์ `mobile/`) ชี้ base URL ของ API ด้วย `EXPO_PUBLIC_API_URL`

```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=http://localhost:3000 npx expo start --web   # หรือสแกน QR ด้วย Expo Go
```

> เปิดบนมือถือจริงให้ตั้ง `EXPO_PUBLIC_API_URL` เป็น IP ของเครื่องที่รัน API (เช่น `http://192.168.1.10:3000`) เพราะ `localhost` บนมือถือคือตัวเครื่องเอง

รหัสผ่านทุกบัญชีคือ `demo1234`

| role | ชื่อ | เบอร์โทร |
|---|---|---|

## flow เต็ม

### 1. เกษตรกร — ลงล็อต
1. เข้าสู่ระบบด้วย `0800000001` / `demo1234` → เข้าหน้า "เกษตรกร"
2. แท็บ **ลงล็อต**: เลือกพืช (เช่น มะม่วง), กรอกน้ำหนัก (เช่น 50), เลือกความสุก, เลือกเกรด, ติ๊ก "ยินดีบริจาค" ได้ตามต้องการ
3. กล่อง preview แสดง **ขายได้อีก X** (สีตามความด่วน) + **ราคาด่วน** + **ราคารวม** โดยดึงจาก `/lots/estimate` แบบ debounce 400 มิลลิวินาที
4. กด **ลงประกาศ** แล้วสลับไปแท็บ **ล็อตของฉัน** เห็นล็อตใหม่พร้อม countdown

### 2. ผู้ซื้อ — จองและดู OTP
1. ออกจากระบบ แล้วเข้าด้วย `0800000011` / `demo1234` → หน้า "ผู้ซื้อ"
2. แท็บ **ตลาดด่วน**: การ์ดล็อตเรียงตามเวลาที่เหลือ มี badge countdown (สีตามความด่วน), ระยะทาง, และราคา
3. กด **จอง** บนล็อตที่ต้องการ
4. แท็บ **การจองของฉัน**: เห็นคำสั่งซื้อพร้อม **OTP ตัวใหญ่** — จำเลข 4 หลักนี้ไว้ให้คนขับตอนส่งมอบ

> ผู้ซื้อประเภทสงเคราะห์ (`0800000012`) จะเห็นปุ่ม **รับบริจาค** บนล็อตที่เปิดรับบริจาค แทนราคาด่วน

### 3. ผู้ประสาน — สร้างรอบวิ่ง
1. ออกจากระบบ แล้วเข้าด้วย `0800000005` / `demo1234` → หน้า "ผู้ประสาน"
2. การ์ด **สร้างรอบวิ่ง**: เลือกคนขับ "คนขับตัวอย่าง" แล้วกด **สร้างรอบ**
3. ระบบดึงออเดอร์ที่ `reserved` มาจัดเป็น pickup (ต่อล็อต) และ drop (ต่อผู้ซื้อ) เรียงเส้นทางแบบเคารพลำดับ pickup ก่อน drop และแสดงรอบใหม่ใน **รอบทั้งหมด**

### 4. คนขับ — รับของและส่งมอบ
1. ออกจากระบบ แล้วเข้าด้วย `0800000004` / `demo1234` → หน้า "คนขับ"
2. กด **ดูจุดแวะ** ที่รอบที่ได้รับมอบหมาย เห็นจุดแวะพร้อมวงกลมลำดับ (pickup สี turmeric, drop สี leaf), ระยะแต่ละช่วง และระยะรวม
3. จุด **รับของ**: กรอกน้ำหนักที่ชั่งได้แล้วกด **ยืนยันรับของ** (ถ้าต่างจากที่แจ้งเกิน 10% ระบบจะตั้ง weight_flag)
4. จุด **ส่งมอบ**: กรอก **OTP** ที่ได้จากผู้ซื้อแล้วกด **ยืนยันส่งมอบ** — กรอกผิดครบ 5 ครั้งจุดจะถูกล็อก และต้องให้ผู้ประสานปลดล็อก

### 5. ผู้ประสาน — จุดน้ำหนักผิดปกติ / ปลดล็อก OTP (ถ้ามี)
1. ที่หน้า "ผู้ประสาน" กด **ตรวจจุดแวะ / ปลดล็อก** ที่รอบนั้น
2. ส่วน **จุดที่น้ำหนักผิดปกติ** แสดง stop ที่ `weight_flag`
3. ถ้า stop ไหนถูกล็อกจาก OTP ผิดครบ 5 ครั้ง จะมีปุ่ม **ปลดล็อก OTP**

### 6. ทุก role — หน้าผลลัพธ์
กดลิงก์ **ผลลัพธ์** ที่แถบบน จะเห็นตัวเลขใหญ่: กิโลกรัมที่ช่วยได้, CO₂e ที่ลดได้, รายได้เกษตรกร, กิโลกรัมบริจาค และจำนวนล็อตที่ส่งมอบ (ดึงจาก `/impact/summary`)

## หมายเหตุด้านการออกแบบ
- ทุกหน้ามีสถานะ **loading**, **error** (พร้อมปุ่มลองใหม่) และ **empty** เป็นข้อความภาษาไทย
- token หมดอายุหรือ API ตอบ 401 → แอป logout อัตโนมัติแล้วกลับหน้า login
- แอปไม่คำนวณราคา/อายุล็อตเอง ใช้ค่าจาก API ทั้งหมด ยกเว้น countdown ที่นับถอยหลังจาก `expires_at`
